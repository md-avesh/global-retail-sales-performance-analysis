# 🌍 Global Retail Sales Performance Analysis
Interactive Executive Sales Dashboard built using Microsoft Excel and Power Query.

## 📖 Executive Summary
This project analyzes global retail sales data to identify business trends, customer behavior, product performance, and revenue insights. An interactive executive dashboard was developed using Microsoft Excel, Power Query, Pivot Tables, Pivot Charts, KPI Cards, and Slicers to support data-driven business decisions.

## 🎯 Business Problem
- Sales reports were scattered across multiple datasets.
- Executives lacked a centralized reporting dashboard.
- Comparing countries and product performance was time-consuming.
- Manual reporting delayed business decision-making.

- ## 🎯 Business Objective
- Develop an interactive executive dashboard that enables business leaders to:

- Monitor Revenue
- Track Orders
- Analyze Customer Behavior
- Compare Product Categories
- Identify Top Products
- Support data-driven decision-making

- ## 📂 Dataset Overview
- | Dataset | Purpose |
|----------|----------|
| Customers | Customer Master Data |
| Products | Product Information |
| Sales | Sales Transactions |
| Stores | Store Information |
| Exchange Rates | Currency Conversion |
